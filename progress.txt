## Feature Goal

Implement a comprehensive admin API surface (`/admin/...`) for Retool integration,
enabling live database management during card shows. Covers trades, buys, sells,
show prep, inventory CRUD, and market lookups. All endpoints gated behind admin
Cognito auth via the existing `require_admin` dependency.

## Workspace Snapshot

- Branch: retool-admin-api
- Base: Polishing-For-Deployment
- Backend: Python 3.12 / FastAPI / DynamoDB (single-table)
- Frontend: Next.js 14 / TypeScript (not touched by this feature)
- Existing admin auth: `dependencies.py:require_admin` — tested, ready to use
- Existing repo layer: `services/dynamodb.py:InventoryRepository` — full CRUD
- Existing models: inventory.py, business.py, catalog.py (Transaction, Show, etc.)
