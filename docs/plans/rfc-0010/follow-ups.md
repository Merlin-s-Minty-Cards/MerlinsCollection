| T0 | **The backend accepts a NEGATIVE `buy_price`.** `_coerce_decimal` checks presence and finiteness, not sign, so `POST /purchases/{id}/items {"buy_price": -5}` is a 200 and confirms into a negative `cost_basis`. `parseMoney` rejects `-5` on the frontend, so no admin UI can produce one — but MCP and curl can | T0's scope named "absent, `None`, or not finite" explicitly.
